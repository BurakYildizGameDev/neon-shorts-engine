YouTube Shorts, TikTok ve Instagram Reels için **100+ gün boyunca kesintisiz, tökezlemeden ve izleyiciyi ekrana kilitleyecek** fizik tabanlı simülasyon videoları üreten 25 modlu otonom içerik fabrikası.

---

## 🌟 Temel Özellikler

* **25 Farklı Viral Oyun Modu:** Bölge savaşı, çarpan şelalesi, altıgen labirent, testereler, saatli bomba, kuantum portalları, yerçekimi kaosu, siber pinball ve daha fazlası.
* **5 Dilde Global İçerik Fabrikası (i18n):** Türkçe (TR), English (EN), Español (ES), Português (PT) ve Deutsch (DE) tam arayüz ve otomatik metadata desteği.
* **Kusursuz H.264 + AAC MP4 İhracı:** Tarayıcının donanım hızlandırmalı `WebCodecs` API'si ve `mp4-muxer` ile doğrudan saf `.mp4` çıktısı.
* **Web Worker & OffscreenCanvas İzolasyonu:** 1680 karelik 1080x1920 render işlemi arka planda işlenir; kullanıcı arayüzü 60 FPS canlı ve akıcı kalır.
* **Saf Matematiksel DSP Ses Motoru:** `Float32Array` üzerinde çalışan ASMR pentatonik melodi dizisi, cam kırılma efektleri, tok bas patlamaları ve frekans süpürmeleri (sıfır harici ses dosyası, %100 telifsiz).
* **480 Hz Sub-Stepping Fizik Motoru:** Her kare alt adımlara bölünerek hesaplanır; yüksek hızlarda bile tünelleme ve obje kayıpları yaşanmaz.
* **Safe Zone Koruması:** TikTok/Reels butonlarının altına yazı veya kritik aksiyon kaçmaz (870x1360 px güvenli çekirdek alanı).
* **Anti-Spam Dinamik Metadata:** Viral kanca formülleri her gün dönüşümlü üretilir, SEO uyumlu başlık ve etiketlerle kaydedilir.

20. **🪙 Çılgın Pachinko (Pachinko Madness):** Tokyo usulü pirinç çivili pachinko masası, lale hazneleri ve Fever modu.
21. **🌀 Boyut Kapıları (Portal Paradox):** Kuantum portallarıyla momentum koruyarak fırlayan sonsuz yerçekimi sapanı.

## 🚀 Hızlı Başlangıç

### Gereksinimler
* Node.js v18+ ve modern bir Chromium tarayıcı (Google Chrome, Microsoft Edge, Brave).

### Kurulum ve Çalıştırma
```bash
# Bağımlılıkları yükleyin
npm install

# Testleri çalıştırın (15 birim testi)
npm test

# Geliştirme sunucusunu başlatın
npm run dev

# Prodüksiyon derlemesi alın
npm run build
```

Tarayıcınızda otomatik olarak `http://localhost:5173` adresi açılacaktır.

## 🎮 Stüdyo Nasıl Kullanılır?

1. **Mod Seçin:** Sol menüdeki 25 viral moddan birine tıklayın. Canlı 60 FPS simülasyon anında sağdaki ekranda başlar.
2. **Dil & Format Seçin:** 5 dilden (TR, EN, ES, PT, DE) birini ve Bölge Savaşı için ülke/takım formatını belirleyin.
3. **Çıktı Klasörünü Seçin:** `[ 📁 Çıktı Klasörünü Seç ]` butonuna basarak hedef indirme klasörünü onaylayın.
4. **Tek Tıkla Üret:** 
   - `[ 🎬 VİDEOYU ÜRET (MP4) ]`: 1080x1920 60FPS sesli MP4 ve `Day_X_info.txt` başlık/açıklama dosyasını diske kaydeder.
   - `[ ⚡ 7 GÜNLÜK SERİ PAKETİ ÜRET ]`: 7 günlük içerik stoğunu multi-worker ile art arda render eder.
